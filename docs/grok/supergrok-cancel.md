# 一、SuperGrok怎么取消？

第一步先确认：

**你最初是在哪里购买的。**

# 二、网页购买的SuperGrok怎么取消？

如果最初通过网页购买：

1. 登录付款时使用的账号；
2. 打开账号设置；
3. 查找：
   - Subscription
   - Membership
   - Billing
   - Manage subscription
   - Premium
4. 找到当前有效套餐；
5. 选择取消订阅或关闭自动续费；
6. 按页面提示确认；
7. 保存取消结果。

完成以后重点检查：

- 是否显示已取消；
- 是否仍有下一次付款日期；
- 当前权益结束日期；
- 是否收到确认邮件。

# 三、X Premium / Premium+怎么取消？

如果 Grok 权益来自 X Premium 或 Premium+：

应该回到 X 对应的会员管理页面。

通常需要：

1. 登录购买时使用的X账号；
2. 进入Premium管理；
3. 查看当前订阅；
4. 进入Manage subscription；
5. 关闭续费或取消套餐；
6. 保存确认结果。

不要把：

**X Premium**

和：

**独立SuperGrok订阅**

默认当成完全相同的产品。

# 四、iPhone / iPad怎么取消SuperGrok？

如果通过 Apple App Store 购买：

1. 打开 iPhone / iPad 设置；
2. 点击顶部 Apple ID；
3. 进入“订阅”；
4. 找到 Grok、X 或对应订阅；
5. 点击取消订阅；
6. 按页面提示确认。

如果 Apple 订阅列表里没有：

说明订单可能不是通过 Apple 建立。

此时继续检查：

- 网页购买；
- X Premium；
- Google Play；
- 其他购买渠道。

---

# 五、Android怎么取消SuperGrok？

如果通过 Google Play 购买：

1. 打开 Google Play；
2. 点击账号头像；
3. 进入“付款和订阅”；
4. 点击“订阅”；
5. 找到 Grok、X 或对应订阅；
6. 点击取消订阅；
7. 按页面提示确认。

如果 Google Play 中没有该订单：

继续检查其他购买渠道。
