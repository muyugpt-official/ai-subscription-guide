## SuperGrok 是什么？

SuperGrok 是 Grok 面向个人用户提供的付费订阅方案。

相较于免费版，SuperGrok 通常提供：

- 更高的功能使用额度；
- 更高的模型访问权限，具体以账号页面为准；
- 更高的聊天、图片、视频或其他工具使用额度；
- 更完整的 Grok 功能体验；
- 更适合日常高频使用的访问体验；
- 可能提供 Connectors、Expert、Grok Build 等功能，具体以地区和账号显示为准。

xAI 官方当前说明中，Grok 可以免费开始使用；付费 SuperGrok 套餐会提高跨产品的使用额度，并解锁更多功能。

Grok 免费版适合体验聊天、搜索和基础 AI 功能。

SuperGrok 更适合需要更高额度、更丰富功能和更高频使用体验的用户。

| 对比项目 | Grok 免费版 | SuperGrok |

| 聊天和基础功能 | 可使用，但可能有限制 | 通常拥有更高额度 |
| 高级模型 | 以账号实际开放为准 | 通常可获得更多访问能力 |
| 图片和视频生成 | 可能有限制 | 通常拥有更高额度 |
| Grok Build、Connectors 等功能 | 以实际开放为准 | 通常拥有更多功能访问机会 |
| 使用频率 | 适合偶尔使用 | 适合日常、高频使用 |
| API 使用额度 | 不包含 | 通常也不包含 |

实际可用的模型和工具可能因地区、账号、系统负载和产品更新而不同，应以账号内显示的信息为准。

## SuperGrok 怎么订阅？

建议优先通过 Grok 官方网页或官方 App 订阅。

不要向第三方提供：

- Grok 或 xAI 账号密码；
- 邮箱验证码；
- 短信验证码；
- 两步验证代码；
- 恢复代码；
- 完整银行卡信息；
- 身份证明文件。

### 方法一：通过 Grok 网页订阅

1. 打开 [Grok 官方网站](https://grok.com/)；
2. 登录自己的账号；
3. 找到升级、套餐、订阅或 Billing / 账单入口；
4. 选择 SuperGrok 或账号页面中可购买的套餐；
5. 查看套餐内容、价格、税费、计费周期和自动续费规则；
6. 选择官方页面支持的付款方式；
7. 确认付款并完成订阅。

付款完成后，通常可以在 Grok 的 Settings / 设置 → Billing / 账单中查看订阅状态。

### 方法二：通过 iPhone 或 iPad 订阅

如果 Grok iOS App 内显示订阅入口，可以通过 Apple App Store 完成购买。

一般流程如下：

1. 下载并打开官方 Grok App；
2. 登录自己的账号；
3. 找到升级或订阅入口；
4. 选择可购买的套餐；
5. 通过 Apple App Store 确认购买；
6. 在 App 或 Apple 的订阅页面查看状态。

通过 Apple App Store 购买后，付款、自动续费、取消和退款通常由 Apple 管理。

### 方法三：通过 Android 订阅

如果 Grok Android App 内显示订阅入口，可以通过 Google Play 完成购买。

一般流程如下：

1. 下载并打开官方 Grok App；
2. 登录自己的账号；
3. 找到升级或订阅入口；
4. 选择可购买的套餐；
5. 通过 Google Play 确认购买；
6. 在 App 或 Google Play 的订阅页面查看状态。

通过 Google Play 购买后，付款和订阅管理通常由 Google Play 管理。

## SuperGrok 有使用限制吗？

有可能存在。

SuperGrok 的主要价值是提高使用额度，而不是保证所有功能都毫无限制。

xAI 官方目前说明中，付费用户的使用额度可能采用共享的每周使用池：

- 聊天、图片、视频、语音、Build 等不同产品可能共用额度；
- 不同功能消耗的计算资源不同；
- 生成高质量视频、进行长时间编码任务等，通常比普通聊天消耗更多额度；
- 具体使用情况可以在 Settings / 设置 → Usage / 使用情况中查看；
- 使用池的重置时间，以账号页面显示的日期和时间为准。

当达到套餐额度时，可能需要等待额度重置、购买额外使用额度，或升级更高套餐。

因此，SuperGrok 不应被理解为完全无限使用。

通常不包含。

SuperGrok 是 Grok 网页和 App 的个人订阅方案。

如果你需要把 Grok 模型接入网站、软件、机器人或自动化工作流，需要单独使用 xAI 的 API 服务，并根据 API 的计费规则付费。

不要把 SuperGrok 订阅当作 API 无限调用套餐。

## SuperGrok 如何取消自动续费？

取消订阅时，必须到原购买平台操作。

### 在 Grok 网页购买

如果是在 Grok 官方网站购买：

1. 打开 [Grok 官方网站](https://grok.com/)；
2. 登录购买订阅时使用的账号；
3. 进入 **Settings / 设置**；
4. 点击 **Billing / 账单**；
5. 找到管理订阅、更新付款方式或取消订阅的入口；
6. 点击取消并按页面提示确认。

如果账单管理页面无法打开，可以尝试：

- 使用浏览器无痕窗口；
- 更换浏览器；
- 暂时关闭广告拦截插件；
- 检查是否有拦截弹窗的浏览器扩展。

### 通过 Apple App Store 购买

如果通过 iPhone 或 iPad 购买：

1. 打开设备的 **设置**；
2. 点击顶部的 Apple ID；
3. 点击 **订阅**；
4. 找到 Grok；
5. 点击 **取消订阅**；
6. 按提示确认。

删除 Grok App 不会自动取消 Apple App Store 中的订阅。

退款通常需要通过 Apple 的退款流程申请。

### 通过 Google Play 购买

如果通过 Android 购买：

1. 打开 **Google Play 商店**；
2. 确认登录的是购买订阅时使用的 Google 账号；
3. 点击个人头像；
4. 点击 **付款和订阅**；
5. 点击 **订阅**；
6. 找到 Grok；
7. 点击 **取消订阅**；
8. 按提示确认。

卸载 Grok App 不会自动取消 Google Play 中的订阅。

## SuperGrok 值得买吗？

以下情况可以考虑订阅 SuperGrok：

- 每天都会使用 Grok；
- 免费版的使用额度经常不够；
- 经常使用图片、视频、语音或高级模型功能；
- 需要更高的 Grok 使用频率；
- 经常处理工作、学习、写作或编程任务；
- 希望使用 Grok 的更多工具和功能。

以下情况可以先使用免费版：

- 只是偶尔聊天；
- 只是体验 Grok；
- 免费版额度一直够用；
- 对付费功能没有明确需求；
- 不确定自己是否会长期使用。

更稳妥的方式是先使用免费版，确认自己确实需要更高额度后，再订阅 SuperGrok。

## 常见问题

### SuperGrok 可以多人共用吗？

不建议。

多人共用账号可能导致聊天记录、文件、付款资料和隐私泄露，也可能触发账号安全限制或违反服务条款。

### SuperGrok 取消后会马上失效吗？

通常不会马上失效。

取消后，一般仍可以使用到当前订阅周期结束。具体到期日期请以 Grok、Apple App Store 或 Google Play 的订阅页面显示为准。

### 网页订阅和 App 订阅可以互相取消吗？

通常不可以。

必须在原购买平台取消：

- 网页购买：在 Grok 网页的 Billing 页面管理；
- Apple App Store 购买：在 Apple 订阅页面管理；
- Google Play 购买：在 Google Play 订阅页面管理。

### 我在多个平台看到订阅，是否会重复扣费？

有可能。

如果在网页、Apple App Store 和 Google Play 等多个平台重复开通订阅，可能出现多笔有效订阅和重复扣费。

重新订阅前，应先确认原有订阅是否已经取消。
