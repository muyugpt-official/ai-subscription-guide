# Claude Code 到底需要什么订阅？Pro、Max 和 API 计费怎么选

> **最后更新：2026 年 9 月 8 日**
>
> **维护方：MuyuGPT**
>
> **说明：** 本文讲清楚用 Claude Code 到底该买哪种订阅、Pro 够不够、什么时候要上 Max、以及它和 Claude API 按量计费的关系。套餐、额度和价格可能随 Anthropic 调整，最终以 Anthropic 官方页面为准。

很多人第一次装 Claude Code，卡在一个问题上：**「它到底要单独付费吗？我是买 Pro、买 Max，还是得去充 API？」**

先给结论，省得你绕路：

> **Claude Code 本身不单独卖。订一个 Claude Pro（或更高的 Max）就能用，它和网页版、桌面版、手机版共用同一个订阅、同一份额度。** 只有当你主动去接 API Key 时，才会变成按量付费的另一套账。

下面把这几条线拆开说。

---

## 一、Claude Code 不是一个单独收费的产品

这是最容易误会的地方。Claude Code 不像有些工具那样自己标个价、单独买。它跟着你的 **Claude 订阅**走。

本次核验时，Anthropic 官方的说法是：Pro 和 Max 订阅都能用 Claude Code，而且是**「一个订阅，网页 / 桌面 / 手机 App + 终端里的 Claude Code 一起用」**。也就是说你不需要为「命令行里那个 Claude」再掏一份钱。

一句话：**先有 Claude 订阅，Claude Code 是这个订阅顺带给你的能力之一。**

---

## 二、免费版能用 Claude Code 吗？

不能。本次核验时，**免费的 Claude 账户不包含 Claude Code。** 想用它，最低要订到 Pro。

所以如果你现在是免费用户、又想在终端里跑 Claude Code，那第一步就是订阅 Pro，没有「免费白嫖 CLI」这条路。

---

## 三、Pro 够用吗？什么时候该上 Max？

对绝大多数个人开发者，**Pro 就是合理的起点。** 日常写代码、改 bug、读项目，Pro 的额度通常够用。

Pro 和 Max 的区别，重点不在「谁更聪明」——本次核验时官方明确，**Max 给的不是更强的模型，而是更多的用量。** 模型和功能是一样的，Max 只是把额度放大。

| 套餐 | 大致定位 | 用量 | 适合谁 |
| --- | --- | --- | --- |
| Free | 不含 Claude Code | —— | 用不了 Claude Code |
| Pro | 入门 | 基础额度 | 日常、轻中度开发 |
| Max 5x | 进阶 | 约 Pro 的 5 倍 | 每天高频用、Pro 额度不够 |
| Max 20x | 重度 | 约 Pro 的 20 倍 | 长时间、大项目、频繁跑 |

判断要不要升级，标准很朴素：**如果你经常没用多久就撞到额度上限、影响干活了，再往上升。** 官方给的路径也是这个逻辑——Pro 不够就上 Max 5x，Max 5x 还不够再上 Max 20x。不用一上来就冲最贵的。

## 四、额度是怎么算的？两个用量窗口要知道

Claude Code 的用量不是「一个月给你一大桶随便用」，而是分层限制。本次核验时，官方的额度是**两层叠加**的：

- 一个**滚动的 5 小时窗口**（短时间内的用量上限）
- 一个**按周计算的周期**（更长时间的总量控制）

还有一点要记住：**Claude Code 和网页 / App 的额度是共用一个池子的。** 你在网页上聊得多，终端里能用的额度就会相应少。包括在 IDE 插件里用 Claude，也是算在同一份额度里。

所以如果你发现额度掉得快，先想想是不是网页端也在大量使用，而不只是 Claude Code 的问题。

---

## 五、订阅额度和 Claude API，是两套完全不同的账

这是本文最需要讲清楚的一点，也是最容易多花冤枉钱的地方。

Claude Code 有两条计费线：

**第一条：跟着订阅走（Pro / Max）。** 用你订阅里包含的额度，按月付固定的钱，用量在上面说的窗口里。这是大多数人该走的线。

**第二条：走 Claude API 按量计费。** 在 console 里预充值，用多少 token 扣多少钱，绑的是海外卡。这是给有特定需求（比如接自己应用、要跑大量自动化）的开发者用的。

两条线不要混。尤其要注意一个坑——

> **如果你的电脑上设置了 `ANTHROPIC_API_KEY` 环境变量，Claude Code 会优先走 API 扣费，而不是用你订阅里已经包含的额度。**

结果就是：你明明订了 Pro，却在按 API 单价被额外收费，订阅的额度反而没用上。本次核验时，官方给的建议是：

- 出现「是否使用 API 额度」的选项时，**如果你想用订阅，就选拒绝**
- 用 `/status` 命令查当前是走订阅还是走 API
- 想确保用订阅，检查一下有没有残留的 API Key 环境变量

顺带说清楚：**Claude Pro / Max 订阅，并不包含给你自己应用调用的通用 API 额度。** 想用 API 做开发，那是单独付费的另一回事。

---

## 六、额度用超了会怎样？

本次核验时，Anthropic 在付费的个人套餐上加了一个**「额外用量」的开关**：撞到订阅额度上限时，不是直接停掉，而是可以选择**继续用、按标准 API 单价计费**，并且你能自己设一个每月花费上限。

要不要开这个开关看你自己：

- 想严格控制花费、不想有意外账单：**别开**，撞到上限就等窗口刷新
- 偶尔赶工不想被卡住：可以开，但记得设好花费上限

## 九、常见问题 FAQ

**用 Claude Code 一定要单独付费吗？**

不用。订一个 Claude Pro 或 Max 就包含它，和网页 / App 共用订阅和额度。

**免费版能用 Claude Code 吗？**

不能。最低要 Pro。

**Pro 和 Max 的区别是模型更强吗？**

不是。模型和功能一样，Max 只是给更多用量。撞额度了再升级。

**Claude Code 的额度和网页版是分开的吗？**

不是，共用一个额度池。网页用得多，终端可用的就少。

**为什么我订了 Pro，还被按 API 收费？**

多半是电脑上设了 `ANTHROPIC_API_KEY`，Claude Code 优先走了 API。用 `/status` 查一下，想用订阅就把 API Key 环境变量去掉、或在提示时拒绝用 API 额度。

**订阅里包含 API 额度吗？**

不包含给你自己应用用的通用 API 额度。那部分是单独按量付费的。

**额度用完就完全不能用了吗？**

可以开「额外用量」开关，按标准 API 单价继续用，并自己设花费上限；不开就等额度窗口刷新。
