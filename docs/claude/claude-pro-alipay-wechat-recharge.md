## 十二、为什么不要提交Cookie和Session Token？

普通用户通常知道：

密码不能随便给别人。

但Cookie和Session Token同样值得注意。

某些会话凭证可能代表一个已经完成登录的有效会话。

如果某个第三方流程要求：

打开浏览器开发者工具  
→ 找Cookie  
→ 复制Session  
→ 提交Token

至少应该先停止操作并确认：

- 这一步为什么必要；
- 会提供什么账号权限；
- 是否存在用户本人完成操作的替代方案。

普通会员订单不应该默认把高权限登录凭证当成普通资料。
