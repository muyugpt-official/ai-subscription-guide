# 术语表

买 AI 会员时最容易混的几个概念，一次讲清。

## 会员 vs API —— 不是一回事
- **会员（订阅）**：在网页/App 里聊天、用各种功能，按月/年付费（如 ChatGPT Plus、Claude Pro）。适合**直接使用**产品的人。
- **API**：给开发者调用的接口，按用量（token）计费，需要写代码或接入工具。**买了会员不等于有 API 额度，反之亦然。**
- 一句话：想直接用 → 买会员；想在自己程序里调用 → 用 API。

## 常见套餐词
- **ChatGPT Go / Plus / Pro**：从入门到高频/重度使用的不同档位；Pro 内还有 5×、20× 之类用量倍率区分。
- **Claude Pro / Max**：Max 面向高频编程与并行任务，5×/20× 指相对 Pro 的用量倍率。
- **Google AI Pro（Gemini）**：Gemini 的付费档，常与 Google One 权益打包。
- **SuperGrok**：Grok 的付费档，相对免费/基础版放开更多用量与功能。

## 交付相关
- **个人号充值**：在你自己的账号上开通会员。
- **兑换 / 自助**：拿到兑换码或链接自行激活。
- **成品号**：直接提供已开通的账号（注意验收与安全项）。

## 付款相关
- **跨境订阅**：官方多以海外支付方式结算，国内卡常被拒。
- **第三方付款协助**：用支付宝/微信解决付款门槛的服务（如 MuyuGPT），**不改变你使用的是哪家产品**。

## 状态词
- **pending（处理中）**：已提交未完成，别急着重试以免重复下单。
- **到账延迟**：扣款成功但权益稍后生效，属常见现象。

> 名称、档位、权益随厂商调整，以官方页面为准。相关变化见[价格与政策变更记录](价格与政策变更记录.md)。
