# 官方帮助中心链接索引

遇到**账号、账单、订阅、退款**这类问题，官方帮助中心通常是最快、最权威的入口。下面是各产品的官方入口（请自行点开确认可用，官方可能调整域名）。

> MuyuGPT 是独立第三方，以下链接均指向各厂商**官方**站点，与本项目无隶属关系。

| 产品 | 官方主站 / 定价 | 官方帮助中心 |
|---|---|---|
| ChatGPT / OpenAI | openai.com ｜ openai.com/chatgpt/pricing | help.openai.com |
| Claude / Anthropic | claude.com ｜ anthropic.com | support.anthropic.com（部分内容已迁至 support.claude.com，以官方跳转为准）|

| Grok / xAI | x.ai ｜ grok.com | help.x.com |

## 什么问题该找官方
- 官方订阅的**账单、退款、发票**
- 账号登录、两步验证、被封申诉
- 官方侧的功能、额度、地区可用性说明

## 什么问题第三方能帮
- 主要是**付款环节**（支付宝/微信解决跨境付款门槛）
- 第三方订单的状态、交付与售后，走对应平台（如 [muyugpt.com/order](https://muyugpt.com/order)）

> 认准官方域名，警惕仿冒钓鱼站。安全事项见[账号安全检查表](账号安全检查表.md)。
