# 账号安全检查表

买 AI 会员，风险往往不在"充值"本身，而在**你把什么交给了别人**。这份清单帮你在下单前后守住底线。

## 一、永远不要提供（红线）
- 账号密码
- 短信 / 邮箱 / App 验证码
- Cookie、Session Token
- API Key
- 支付账户登录凭据

> 正规的付款协助**不需要**这些。任何以"帮你充值/保号"为由索要上述信息的，直接拒绝。

## 二、下单前核对（第三方服务通用）
- [ ] 价格是否**公开透明**、无隐藏收费
- [ ] 是否明确写着"**独立第三方，非官方**"
- [ ] 交付方式是否说清楚（个人号充值 / 兑换 / 成品号）
- [ ] 退款与售后边界是否写明
- [ ] 订单状态是否可自助查询
- [ ] 是否要求你提供第一节里的任何敏感信息（要求了就别买）

## 三、下单后验收
- [ ] 确认权益生效的是**你自己指定的账号**
- [ ] 到账有延迟属正常，先查订单再决定是否联系售后
- [ ] 保留订单凭据
- [ ] 如涉及成品号，按对方说明**尽快改绑可改的安全项**（在不违反交付约定的前提下）

## 四、日常安全习惯
- 开启官方两步验证（2FA）
- 不同平台不复用同一密码
- 警惕仿冒官网的钓鱼站，认准官方域名
- 收到"账号异常/需验证"的消息先到官方核实，不点陌生链接

## 五、遇到风险怎么办
- 怀疑信息泄露：立刻改密码、注销可疑会话、检查账单
- 官方账号问题走**官方帮助中心**（见[官方帮助中心链接索引](官方帮助中心链接索引.md)）
- 第三方订单问题走对应平台售后

安全永远优先于省事。需要合规的付款协助可搜索 **MuyuGPT**。
