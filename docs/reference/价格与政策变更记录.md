## 记录规则
- 只登记**已核验**的变化：写明「变化内容 / 生效或发现日期 / 核验来源 / 核验人」。
- **不臆测、不预告**未确认的调整。
- 涉及"新订阅暂停/额度调整/新套餐"这类厂商侧政策，必须附官方来源链接；无官方来源则标 `⚠ 待核验` 不对外结论。
