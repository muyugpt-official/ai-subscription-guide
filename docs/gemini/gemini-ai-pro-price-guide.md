## 30 秒结论

- **没有一个适用于所有人的"Google AI Pro 价格"**：价格取决于你所在的国家和地区、付款渠道（网页 / 应用商店）、计费周期、税费和当时的促销，所以网上任何写死的数字都值得怀疑。
- 最可靠的价格，是**你登录后在结账页面看到的那个**。
- 别把"订阅价格"和"成品号价格"混在一起比：前者买的是你自己账号上的订阅，后者买的是一个已开通的账号，交付和风险都不同。

## 影响价格的因素

| 因素 | 说明 |
| --- | --- |
| 国家和地区 | 方案页说明可用范围因国家而异；档位、权益和价格都可能不同 |
| 付款渠道 | 网页订阅和应用商店（Apple / Google Play）订阅的价格、币种可能不同 |
| 计费周期 | 月付、年付，或第三方提供的季度、年度时长 |
| 税费 | 不同地区的税费处理不同，标价可能含税也可能不含 |
| 促销和优惠 | 如新用户优惠、学生优惠（方案页写到 Plus 有学生一年免费的活动），有时限 |
| 档位本身 | Plus、Pro、Ultra 是不同系列；Ultra 现在还分 5x 与 20x 两档 |

## 怎么查你所在地区的价格

1. 用你实际要订阅的 Google 账号，打开 [Google AI 方案页](https://one.google.com/about/google-ai-plans/)，选择对应地区版本，看当前显示的价格；
2. 点击订阅，看**结账页面最后一步**的金额、币种、是否含税和计费周期——这才是实际要付的；
3. 如果你在手机上订阅，再对比应用商店里显示的价格；
4. 记录下页面日期和截图，价格可能调整。

## 判断一个报价是否合理

不写数字，但可以问这几个问题：

| 问题 | 为什么重要 |
| --- | --- |
| 报价对应的是哪一档（Plus / Pro / Ultra 5x / Ultra 20x）？ | 档位不同，价格差别很大 |
| 是订阅到你自己的账号，还是交付一个现成账号？ | 决定了账号控制权和风险 |
| 时长是多久？ | 月、季、年的单价不能直接比 |
| 包含什么服务费、手续费？ | 总成本不只是标价 |
| 失败或账号出问题怎么处理？ | 便宜但没有售后，成本可能更高 |
| 明显低于官方的价格，低在哪里？ | 低得离谱往往意味着风险，见 [AI 会员代充安全](https://github.com/muyugpt-official/gpt-daichong) 的自查思路 |

## 订阅价格 vs 成品号价格

| | 订阅到你自己的账号 | 成品号 |
| --- | --- | --- |
| 买到什么 | 你账号上的订阅 | 一个已开通 AI Pro 的账号 |
| 价格构成 | 官方标价（或第三方服务价） | 服务商的定价，包含账号成本和质保 |
| 账号控制权 | 在你手里 | 取决于交付说明，需要按指引首登并加固 |
| 风险 | 支付、地区限制 | 账号被收回、质保期外的问题 |

## 常见问题

### Google AI Pro 现在多少钱？
本文不写数字。请以你所在地区的官方方案页和结账页面为准。

### 为什么别的文章写的价格和我看到的不一样？
因为价格随国家、渠道、周期、税费和促销变化，而且很多文章没有标明核验日期。

### 年付一定比月付划算吗？
通常可以比较折算后的单月价格，但要确认年付是否一次性扣款、到期是否自动续费，以及中途是否可以退款。

### Plus 和 Pro 差多少钱值得升级？
先看你会用到哪些独有权益（存储、用量倍数、办公应用集成等），再看价差，见 [Google AI 套餐手册](https://github.com/muyugpt-official/gemini-chongzhi/blob/main/docs/google-ai-plans-2026.md)。

### 订阅里的 Google Cloud 额度，算不算省钱？
方案页只写了每月的额度金额，没有说明可用范围；是否真的用得上、能抵哪些费用，取决于你的使用方式，本文不作推断。
