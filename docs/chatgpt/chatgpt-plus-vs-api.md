# 十六、Token是什么？

可以简单理解为：

**模型处理文本时使用的计费和长度单位之一。**

它并不完全等于：

* 一个汉字
* 一个英文单词
* 一个字符

实际Token数量由模型的分词方式决定。

API请求通常会涉及：

* 输入Token
* 输出Token

因此提示词越长、返回内容越多，通常意味着更多Token使用。
